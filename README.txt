99HOMES HTML/CSS/JAVASCRIPT WEBSITE

FILES
- index.html: page structure and content
- styles.css: complete responsive design
- script.js: mobile menu, project search/filter, WhatsApp inquiry form

HOW TO RUN
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Double-click index.html to open it in your browser.
4. For development, open the folder in VS Code and use Live Server.

IMPORTANT BEFORE SHOWING OR LAUNCHING
- This is an independent redesign concept, not an approved official 99homes website.
- Verify brokerage phone, address, projects, developer details, prices, completion dates and availability with the brokerage.
- Replace illustrative stock photos with approved/licensed project photography.
- The contact form opens WhatsApp and does not save form data.
- Confirm written approval for use of the company's name, logo/branding, content, photos and claims.
- Update the WhatsApp number in script.js if the brokerage confirms a different lead number.
